# textlint-plugin-comments

[![GitHub License](https://img.shields.io/github/license/cffnpwr/textlint-plugin-comments?style=flat)](./LICENSE)

ソースコード・設定ファイルのコメントを[textlint](https://textlint.org/)で検査するためのパッケージのモノレポです。

プラグインは、コメントだけを検査対象にします。
フィルタールールは、コードのコメントに文書とは異なる書き方の規則を適用します。
